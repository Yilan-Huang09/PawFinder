# PawFinder 测试用例

## 自动化覆盖

| 层级 | 命令 | 主要覆盖 |
| --- | --- | --- |
| 数据库 | 依次执行 `database/tests/01` 至 `04` | 表、约束、函数、视图、触发器、存储过程、种子数据 |
| 后端 | `.venv/Scripts/python -m pytest backend/tests -q` | 权限、状态流转、上传、匹配、任务并发、寻回事务、通知、管理 |
| 前端 | `npm test --prefix frontend` | 路由守卫、表单、地图回退、匹配审核、任务、消息与管理组件 |
| 构建 | `npm run build --prefix frontend` | TypeScript、Vue 模板与生产打包 |
| 端到端 | `npm run test:e2e` | 主人 → 目击者 → 匹配 → 志愿者 → 寻回完整故事 |

## 核心人工用例

1. 未登录访问 `/pets`，应跳转登录并保留回跳地址。
2. 普通用户访问 `/admin`，应被路由守卫送回宠物档案；直接请求管理 API 应返回 403。
3. 上传伪装成图片的文件或超过 5 MB 的图片，应显示校验错误且不创建照片记录。
4. 两名志愿者同时认领同一任务，只允许第一人成功，第二人收到 409 冲突提示。
5. 任务完成时不填写反馈，应禁止提交；填写反馈后记录完成时间。
6. 事件主人确认寻回后，事件变为 `REUNITED`，未完成任务统一取消，再次确认返回冲突。
7. 不设置 `VITE_AMAP_JS_KEY` 时，地图区域应显示 OpenStreetMap、最后位置、目击与搜寻区坐标列表。
8. 设置无效地图密钥或高德地图脚本加载失败时，应自动回退到 OpenStreetMap 与坐标列表。
9. 不设置模型服务时，描述优化仍返回本地模板；远端超时也应回退本地结果。
10. 联系电话在公开案件页脱敏，主人和管理接口按权限读取完整数据。

## 演示前快速检查

- 数据库 11 张表、3 个视图、函数、触发器和 `sp_confirm_reunion` 均存在。
- 首页、公开列表、详情、工作台和管理页在 1440px 与手机宽度下无横向溢出。
- 演示账号密码与 README 一致，浏览器中没有遗留其他账号会话。
- 地图与模型都先演示正常降级，再按需演示外部服务。
