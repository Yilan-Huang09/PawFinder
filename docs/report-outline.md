# 数据库课程设计报告提纲

1. 绪论：现实问题、目标、环境。
2. 需求分析：角色、流程、功能和非功能需求。
3. 概念设计：实体、联系、E-R 图和基数。
4. 逻辑设计：11 张表、主外键和第三范式。
5. 物理设计：字段、索引、删除策略和查询计划。
6. 数据库对象：距离函数、视图、触发器、寻回存储过程。
7. 系统实现：API、页面、上传、匹配与降级。
8. 测试：SQL、SQLite/MySQL、组件和 E2E。
9. 创新点：独立线索池、可解释匹配、区域协作、事务闭环。
10. 总结与扩展。
