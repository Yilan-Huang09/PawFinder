# PawFinder 现场演示脚本

## 演示前准备

1. 运行 `scripts/preflight.ps1`，保存测试通过画面。
2. 重置固定种子数据，启动网站并预先打开数据库客户端。
3. 准备 `linyu`、`witness`、`zhaomin`、`admin` 四个账号，统一密码为 `PawFinder123!`。

## 8 分钟演示顺序

1. **00:00–00:40 首页与问题**：说明项目服务重庆北碚、西南大学周边，展示真实地图和正在寻找事件。
2. **00:40–01:20 数据模型**：用 E-R 图解释主人、宠物、走失事件、独立目击和多对多匹配。
3. **01:20–02:10 主人端**：用 `linyu` 登录，展示“点点”档案、事件详情、脱敏联系方式和真实地图。
4. **02:10–03:00 目击端**：用 `witness` 提交一条独立目击，强调不预先绑定某个走失事件。
5. **03:00–04:00 可解释匹配**：切回主人，展示外观、距离、时间分项及总分，确认候选。
6. **04:00–05:00 协作任务**：展示搜寻区域；用 `zhaomin` 认领、开始并填写反馈，说明原子认领防冲突。
7. **05:00–06:00 寻回事务**：主人确认寻回，展示事件变为 `REUNITED`、区域关闭、任务归档和通知同时完成。
8. **06:00–06:40 管理端**：用 `admin` 展示统计、账号状态与内容治理。
9. **06:40–07:30 数据库亮点**：展示视图、距离函数、触发器、`sp_confirm_reunion` 和一个 `EXPLAIN`。
10. **07:30–08:00 测试与总结**：展示自动测试结果，概括可解释匹配、协作搜寻和事务闭环。

## 备用说明

- 高德密钥未配置时使用 OpenStreetMap 真实地图；外部地图异常时仍保留地址和坐标列表。
- 大模型接口未配置时使用本地模板，不影响匹配分数和核心流程。
- 若现场网络不稳定，优先演示固定种子、数据库对象和本地自动测试。
