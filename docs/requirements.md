# PawFinder 需求说明

## 项目目标

让主人快速发布结构化走失信息，让目击者独立记录线索，让志愿者分区协作，并在数据库层可靠完成寻回归档。

## 角色与权限

| 角色 | 权限 |
| --- | --- |
| 游客 | 浏览公开事件、脱敏联系方式和公开目击 |
| 注册用户 | 维护自己的档案与线索，认领任务 |
| 事件主人 | 发布事件、审核匹配、创建区域、确认寻回 |
| 管理员 | 查看统计、停用账号、管理事件与线索状态 |

## 功能与质量要求

1. 用户注册登录、资料和密码维护；停用后令牌立即失效。
2. 宠物支持多照片和唯一封面；走失事件、目击均记录时间与坐标。
3. 匹配保存三个分项、总分、距离、原因、版本和人工审核状态。
4. 每个区域生成一个任务，同一时刻只能由一名志愿者认领。
5. 寻回必须原子更新事件、区域、任务、宠物和通知。
6. 使用外键、唯一、检查、触发器和事务保证完整性。
7. 使用密码哈希、JWT、资源所有权、文件类型与路径校验保证安全。
8. 地图和模型服务失败时核心流程仍可运行。
